# 远程设备固件分批发布控制台

源提示词摘要：发布负责人选择设备范围、固件版本、分批比例和回滚版本，运维设定兼容条件与失败阈值，值班人员监视下载、安装、重启和异常事件；关键发布支持审批、暂停、继续和紧急回滚，过期状态不可误用。

## 技术栈

Angular、TypeScript、Angular Material、NgRx、Angular Router、RxJS、Angular CDK、Transloco。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62026`

## 可用流程

- 创建发布批次并关联设备分组、固件版本、分批比例和失败阈值。
- 批次从草稿、已审批、发布中、暂停到完成或回滚（回滚中/已回滚）。
- 兼容条件阻止不合格分组加入发布；实时指标由本地遥测模拟驱动。
- 暂停（手动或失败率超阈值自动暂停）时留存失败快照：已更新/失败数量、失败率、阈值、暂停原因与时间。
- 暂停后必须由处理人填失败原因与处置说明，再经发布负责人重新审批，“继续”按钮才会放开。
- 紧急回滚仅对已发布批次开放（草稿/已审批无入口），按已更新设备逐台推进为“回滚中”，记录目标版本、已回滚数量、回滚失败数量与完成时间，全部处理完才结束。
- 审批、暂停、继续、回滚和状态变化保留审计记录并持久化到 localStorage，重新打开页面后失败快照与回滚记录仍在。
